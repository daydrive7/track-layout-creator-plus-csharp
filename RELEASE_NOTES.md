# TLC+ C# v1.0.3

- Removed custom panel and canvas colors. Dark/light themes and all accent-color options remain. Older panel/canvas overrides are ignored.
- Moved Road Types from Geometry to Decorations.
- Added a road-type icon beside the decoration tool in the top-left canvas toolbar. It opens the sidebar at the road-type controls.
- Corrected inactive toolbar button backgrounds, including zoom, reverse and screenshot actions. Only the selected tool stays highlighted.

TRK5/TED formats and the fading error notices are unchanged.

Download the complete win-x64 ZIP and extract all files. Keep Assets beside TLCPlus.exe. The separate EXE download requires the assets ZIP. Source and SHA256 checksums are provided. MIT licensed.
