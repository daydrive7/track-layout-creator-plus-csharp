# TLC+ C# v1.0.0

Native Windows C# port of TLC+ Python 1.3.0.

- TRK5/TED editing and export, terrain, banking, manual elevation and isometric preview.
- 2,000 decorations with original scenery artwork and compact palette layout, including Andalusia.
- Nine languages, concise localized credits, dark/light themes, accent and custom canvas/panel colors.
- Live node editing with height updates, independent number/property labels and an elevation-only position marker.
- Native C# release checking, draggable empty menu-bar space and consistent menu colors.

## Downloads

- **TLCPlus-CSharp-v1.0.0-win-x64.zip** — recommended complete portable program.
- **TLCPlus.exe + TLCPlus-CSharp-v1.0.0-assets.zip** — separate executable/assets option; both are required.
- **TLCPlus-CSharp-v1.0.0-source.zip** — clean source, tests and documentation.
- **SHA256SUMS.txt** — asset checksums.

Extract all files before launching. Keep Assets beside TLCPlus.exe. MIT licensed.

TRK5 companion metadata retains decoration/extra height settings. Some native UI behavior, random generation and tracing differ from Python. The included suite verifies 78 Python TED comparisons and 156 fixture round trips; in-game GT6 loading remains unverified.
